Help & Support

Need help getting Stream Sync set up, or want to report a bug? You’re in the right place.

Join the support Discord
Get real-time support, share ideas, and help shape future updates.

If you run into issues, the fastest way to get help is via the Syndicate AI Discord.

When you report a bug, please include:

  • A short description of what you were doing
  • Your Stream Sync version
  • Any error popups you saw
  • Relevant log files (from the logs folder)

The log files only contain technical details releated to Stream Sync – no personal data related to your chat content or viewer data is ever stored.

Logs are automatically retained for 7 days. Purging logs will delete all log files except the current day's log.

Backup & restore
Move overlays, settings, fonts, event media, and imports between machines with a .zip file.

Export saves a backup you pick a location for. Restore opens a .zip and writes those files into this Stream Sync install. Use this before reinstalling Windows or moving to a new PC.

  • Chat & events overlay profiles
  • Uploaded fonts and localized event media
  • StreamElements import data
  • Optional recent logs (export only)

Restore does not bring account logins with it. Reconnect Twitch, Kick, and StreamElements after restoring. Takeover keys are never in the zip.
